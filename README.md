# Zapret GUI · 0.3.0

Лёгкое нативное приложение Windows 10/11 x64 для Flowseal Zapret и TG WS Proxy. Python, Node.js и .NET устанавливать не нужно. MCP необязателен; встроенного ИИ-чата нет.

## Начало работы

1. Скачайте `ZapretGUI.exe` из [последнего релиза](https://github.com/vladimir-mezh/zapret-gui/releases/latest) и откройте его. Приложение установит себя в папку пользователя и создаст ярлык в меню «Пуск».
2. На главной странице нажмите **Установить и включить**. GUI сам скачает официальный стабильный релиз Flowseal, распакует его и выберет `general.bat`.
3. Подтвердите запрос прав администратора Windows для установки службы. Служба запускается автоматически с Windows и работает после закрытия GUI.
4. Если стратегия не подходит вашему провайдеру, выберите другую и нажмите **Применить настройки**. Автоматический подбор стратегии пока не реализован.

При существующей службе `zapret`, установленной другой программой, GUI сохраняет её и сообщает о конфликте. Для перехода сначала удалите службу через прежний менеджер. GUI не удаляет сторонние службы или процессы.

## Возможности

- **Главная:** включение, выключение, применение профиля, удаление службы из автозапуска.
- **Версии:** последняя версия в одну кнопку; список стабильных релизов; установка выбранной версии; удаление версии, скачанной GUI; импорт имеющейся папки. Старые версии и списки сохраняются. Для внешних папок доступно только удаление регистрации.
- **Telegram:** установка и обновление официального TG WS Proxy, создание локальной конфигурации, запуск, подключение через `tg://proxy`. Telegram Desktop сам запрашивает подтверждение подключения.
- **Тесты:** проверка HTTPS без изменения службы; тест выбранной стратегии или всех стратегий; остановка и сохранение JSON-отчёта. Рекомендация выбирается по доступности Discord/YouTube, затем других целей и времени ответа. Перед применением её нужно выбрать и нажать «Применить настройки».
- **Настройки:** Game Filter, режим IPSet, обновление списка IP с резервной копией; пользовательские списки сайтов и исключений; замена активных UDP-фейков для Discord и игр с резервной копией. Изменения применяются через главную страницу.
- **MCP:** установка и обновление из отдельного репозитория; автоматическая настройка Codex, Claude Desktop или Claude Code; состояния подключения. После первого подключения нужно перезапустить ИИ-клиент. Другие записи сохраняются, создаётся резервная копия файла.
- **Диагностика:** состояние службы, BFE, сетевых программ, прокси и записей hosts; наличие файлов; очистка кэша закрытого Discord с переносом в резервные папки; экспорт контекста, обновление GUI. Новая версия устанавливается рядом с предыдущей.

## Параллельный подбор

Режим **«По 3 одновременно»** проверяет до трёх стратегий за раз. Каждая получает отдельный диапазон локальных TCP-портов; тестовые соединения curl привязаны к этому диапазону, а фильтры WinDivert не пересекаются. Реальный локальный порт каждого успешного запроса проверяется. Сайты внутри стратегии тоже проверяются параллельно, до четырёх одновременно. После сравнения победитель проверяется отдельно с исходным фильтром стратегии. Скорость зависит от сети и тайм-аутов; гарантии ускорения в три раза нет.

Параллельный режим экспериментальный: разделение запросов проверено в живой сети, фильтры проверены библиотекой WinDivert, но полный прогон нескольких процессов `winws` с драйвером ещё требует проверки. Доступен обычный режим **«По одной стратегии»**. При отсутствии системного curl используется последовательный WinHTTP-тестер. Поддержка нескольких процессов с непересекающимися фильтрами описана в [документации winws](https://github.com/bol-van/zapret/blob/master/docs/windows.en.md).

Тесты читают `utils/targets.txt` установленной версии (HTTPS-цели). Они создают отдельную защищённую копию файлов, временно используют IPSet `any` и приостанавливают только службу GUI; после теста возвращают прежнее состояние. Чужой работающий обход не завершается. Закрытие окна отменяет тест; отмена может занять несколько секунд. При ошибке восстановления GUI сообщает об этом. Тестовые копии могут оставаться в папке `engine/tests`.

Это тест TLS/HTTP: любой ответ HTTP означает установленное TLS-соединение, включая 403/404. Он не подтверждает воспроизведение видео, работу голоса Discord, QUIC, ICMP или отсутствие блокировки после передачи 16–20 КБ. VPN влияет на результаты. Полный официальный тест TCP 16–20 в эту версию ещё не перенесён.

## Источники

Адреса заданы в приложении — пользователю не нужно вводить ссылки:

- [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
- [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)
- [vladimir-mezh/zapret-gui-mcp](https://github.com/vladimir-mezh/zapret-gui-mcp)
- [vladimir-mezh/zapret-gui](https://github.com/vladimir-mezh/zapret-gui)

Файлы Flowseal скачиваются через HTTPS. Если релиз содержит SHA-256 в GitHub release API, контрольная сумма проверяется; старые релизы без опубликованной суммы тоже поддерживаются. ZIP распаковывается с проверкой путей, количества файлов и размера. MCP проверяется по манифесту API и контрольным суммам.

## Хранение

Настройки и скачанные версии: `%LOCALAPPDATA%\ZapretGUI`. Служба использует копию выбранной версии в `%ProgramFiles%\ZapretGUI\engine`; эту папку могут изменять только администраторы и SYSTEM. Импортированные папки не удаляются.

MCP использует тот же профиль и контроль ревизий. MCP меняет профиль; применение параметров к службе выполняется через GUI. Ключи OpenAI/Anthropic не нужны. Telegram-прокси слушает локальный адрес 127.0.0.1.

## Сборка

C++17 / Win32 / GDI; CMake + MSVC или переносимый Zig 0.15.2:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-mcp.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test_manager.ps1
python .\tests\mcp_integration.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test_backend.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\test_testing.ps1 -Live
```

`build.ps1 -Output ZapretGUI-0.3.0.exe` позволяет собрать новое имя, если предыдущий EXE открыт. `--settings` запускает GUI без установки, для разработки. MCP собирается отдельно и экспортируется через `export-mcp-repo.ps1`.

## Границы версии

Нет постоянного мониторинга Discord/YouTube и переключения при сбоях. Статус «обход включён» означает работающую службу, а не доказанную доступность каждого сайта. Изменение hosts через GUI и раздельные диапазоны Game Filter TCP/UDP ещё не подключены.

Проверяются реальная загрузка релизов, распаковка, сохранение списков, разбор стратегий, настройки ИИ-клиентов и stdio MCP. Запуск драйвера и доступность сайтов требуют отдельной проверки на компьютере пользователя с подтверждёнными правами администратора.
