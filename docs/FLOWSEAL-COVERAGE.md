# Возможности Flowseal и GUI 0.4.0

Основа: меню service.bat, utils/targets.txt и utils/test zapret.ps1 Flowseal 1.10.3. Интерфейсы [redlyaguha/zapret-gui](https://github.com/redlyaguha/zapret-gui), [MelDxKviel/zapret-ui](https://github.com/MelDxKviel/zapret-ui) и [medvedeff-true/Zapret-Gui](https://github.com/medvedeff-true/Zapret-Gui) изучены как примеры возможностей; их код не скопирован.

| Возможность | В GUI | Граница поддержки |
|---|---|---|
| Install/Remove Service | Главная | Управляется только собственная служба GUI |
| Check Status | Главная, диагностика | Статус процесса/службы отдельно от доступности сайтов |
| Временный запуск | Главная → Пока открыт GUI | Скрытый собственный процесс; остановка при выходе/гибели GUI, без установки службы |
| Game Filter | Настройки → Игры и списки | Все 4 режима и отдельные диапазоны TCP/UDP |
| IPSet Filter | Настройки → Игры и списки | loaded/none/any с резервным списком |
| Auto-Update Check | Настройки → Поведение | GUI/Zapret/MCP/TG: раз в сутки, установка по кнопке |
| Replace active fakes | Настройки → Игры и списки | Discord/Game UDP, резервная копия |
| Update IPSet List | Настройки → Игры и списки | Официальный .service/ipset-service.txt, проверка IP/CIDR, режим фильтра сохраняется |
| Update Hosts | Настройки → Адреса сайтов | Просмотр официального .service/hosts, применение с резервной копией; удаляется только блок GUI. Конфликт с пользовательской записью требует разрешения пользователем |
| Run Diagnostics | Диагностика | BFE, активные службы/процессы, прокси, записи hosts, файлы. Системные защиты не отключаются |
| Clear Discord Cache | Диагностика | Закрыть stable/PTB/Canary; папки переносятся в резервные, не удаляются |
| Standard Tests | Тесты | HTTPS + отдельные TLS 1.2/1.3; ICMP для IPv4 PING-целей из targets.txt. Пинг не влияет на выбор стратегии |
| TCP 16–20 freeze | Тесты → DPI | Набор hyperion-cs, HTTP/1.1 + TLS 1.2/1.3, случайные 64 КБ POST, получение ≥32 КБ. Тайм-аут — подозрение, не доказательство блокировки |
| Все стратегии одновременно | Тесты | До 128; отдельные локальные TCP-порты и WinDivert-фильтры, стартовый барьер и повторная отдельная проверка победителя |
| Свои цели | Тесты → Адреса для проверки / utils/targets.txt | До 32 уникальных HTTPS-целей, числовые IPv4 PING-цели в расширенном режиме |
| Профили | Настройки → Профили и стратегии | Сохранение/выбор/удаление, импорт/экспорт JSON, версия должна быть установлена |
| Свои стратегии | Настройки → Профили и стратегии | BAT импортируется как параметры без выполнения команд; отдельное имя по хешу, сохраняется при обновлении |
| Трей | Настройки → Поведение | Открыть окно, включить/выключить обход, выйти; закрытие в трей выключено по умолчанию |
| Журнал | Настройки → Журнал движка | Временный процесс: stdout/stderr, подробный режим отдельно, экспорт, ограничение 1 МБ |

Параллельная изоляция проверена библиотекой WinDivert и живыми запросами curl с контролем локального порта. Стартовый барьер и владение всеми 22 процессами проверены исполняемыми локальными тестовыми процессами. Полный прогон нескольких настоящих winws с драйвером и запуск через UAC остаются границей проверки; тестовые процессы не выдаются за доказательство работы обхода.

В 0.4.0 ещё нет проверки воспроизведения видео/голоса Discord/HTTP3-QUIC, автоматического переключения обхода при сбоях, генератора новых стратегий, полного журнала службы, тем/локализации и поиска IP-списков в интернете. Это не заявление о полном равенстве всем сторонним GUI.
