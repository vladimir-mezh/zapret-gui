# Возможности Flowseal и GUI 0.3.0

Основа сравнения: меню `service.bat` и `utils/test zapret.ps1` релиза Flowseal 1.10.3. Интерфейсы [redlyaguha/zapret-gui](https://github.com/redlyaguha/zapret-gui) и [MelDxKviel/zapret-ui](https://github.com/MelDxKviel/zapret-ui) изучены как примеры поведения; их код в приложение не скопирован.

| Flowseal | В GUI | Ограничение |
|---|---|---|
| Install/Remove Service | Главная | Только служба, созданная GUI; другие менеджеры сохраняются |
| Check Status | Главная, диагностика | Статус службы не подтверждает доступность сайтов |
| Game Filter | Настройки | Пока только включение TCP+UDP; раздельные режимы и диапазоны позже |
| IPSet Filter | Настройки | loaded/none/any с сохранением исходного списка |
| Auto-Update Check | Кнопки обновления GUI, Zapret, MCP | Автоматической фоновой проверки пока нет |
| Replace active fakes | Настройки | Discord/Game UDP, резервная копия |
| Update IPSet List | Настройки | Официальный источник и резервная копия |
| Update Hosts | Диагностика записей | Изменение системного hosts пока не реализовано |
| Run Diagnostics | Диагностика | Основные службы, процессы и прокси; исправления системных настроек не выполняются |
| Clear Discord Cache | Диагностика | Требует закрыть Discord; кэш переносится, а не удаляется |
| Standard Tests | Тесты | HTTPS, выбранная или все стратегии; без ICMP и отдельных режимов TLS 1.2/1.3 |
| TCP 16–20 freeze | Пока нет | Не выдаём обычную проверку TLS за тест передачи данных |
| Custom targets | `utils/targets.txt` | HTTPS, до 32 уникальных целей |

Параллельный тест использует штатный `--wf-raw` и отдельные локальные порты curl. Оригинальные стратегии не меняются. На время теста создаётся копия установки с IPSet `any`; исходные списки сохраняются. Лучший параллельный результат проверяется повторно с обычным фильтром. Режим требует дальнейшей проверки с реальными параллельными `winws` на компьютере без стороннего работающего обхода.
