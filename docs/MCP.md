# MCP для Zapret GUI · 0.3.1

В GUI откройте **MCP**, выберите Codex, Claude Desktop или Claude Code и нажмите **Подключить выбранный ИИ**. GUI скачает последний стабильный MCP из [отдельного репозитория](https://github.com/vladimir-mezh/zapret-gui-mcp/releases/latest), проверит файлы и добавит сервер в настройки выбранного клиента. Перезапустите клиент после первого подключения. Другие записи сохраняются, создаётся резервная копия файла.

После обновления MCP повторно добавлять сервер не нужно: постоянный `ZapretMcpLauncher.exe` выбирает активную версию из `manager.json`. Уже запущенный клиент продолжает работать со старой версией до переподключения. Старые бинарники сохраняются.

GUI не хранит ключи OpenAI/Anthropic. MCP запускается ИИ-клиентом через stdio, не открывает сетевые порты и не содержит чата. Статус подключения появляется после handshake и проверяется по живому процессу и времени его создания.

## Инструменты

| Инструмент | Возможности |
|---|---|
| `zapret_get_state` | Профиль, ревизия, доступные версии и стратегии |
| `zapret_set_profile` | Предпросмотр по умолчанию, сохранение с `dry_run: false` и актуальным `expected_revision` |
| `zapret_import_version` | Регистрация существующей распакованной папки Flowseal |
| `zapret_check_files` | Проверка наличия файлов без изменения Windows |

Изменённый профиль отображается в GUI. Для применения к службе нажмите **Применить настройки** на главной странице. MCP не запускает произвольные команды, службы или установщики.

Поддерживаются ревизии handshake 2024-11-05, 2025-03-26, 2025-06-18 и 2025-11-25. Новые клиенты должны поддерживать совместимый режим.

## Другие клиенты

Нажмите **Копировать подключение** и импортируйте JSON в клиент с поддержкой локального stdio MCP. Обычный сайт с чат-ботом сам по себе не получает доступ к локальному серверу.

Настройки: `%LOCALAPPDATA%\ZapretGUI\settings.json`. GUI и MCP должны работать от одного пользователя Windows. Аргумент `--config <путь>` предназначен для тестов и изолированных профилей.

## Выпуск

Версия MCP независима от GUI. Релиз содержит `ZapretMCP.exe`, `ZapretMcpLauncher.exe` и `mcp-manifest.json` с `api_version: 1`, SHA-256 обоих EXE и лицензией JSON-библиотеки. ZIP доступен для ручной установки. Контрольная сумма обнаруживает повреждение; источником доверия остаётся официальный репозиторий этого проекта.

## Расширенный Game Filter

GUI 0.4.0 использует schema 2; сервер читает schema 1 и 2, а перед первым сохранением старой схемы делает резервную копию. В `zapret_set_profile.changes` доступны `game_mode` (`disabled`, `all`, `tcp`, `udp`), `tcp_ports` и `udp_ports` (например `27015,27020-27050`). Старое поле `game_filter` сохранено: true выбирает all, false — disabled. При совместной передаче явно заданный `game_mode` определяет режим. Допустимы только числовые порты 1–65535 и возрастающие диапазоны; произвольные команды отвергаются.

MCP 0.3.1 сохраняет schema 1 при обычных изменениях старых полей с режимами all/disabled и стандартными диапазонами, поэтому отдельное обновление MCP не ломает GUI 0.3.0. Расширенные режимы/порты требуют GUI 0.4.0: перед их сохранением выполняется переход на schema 2 с резервной копией. Файл schema 2 никогда не понижается до schema 1.
